**Breakpoints** is a specialized mobile application developed for the **"Future Fighters Against AMR"** competition, organized by the **Egyptian Drug Authority (EDA)** in collaboration with the **World Health Organization (WHO)**.

The application is tailored for dental and oral health professionals to support clinical decision-making, promote responsible antibiotic prescribing, and combat Antimicrobial Resistance (AMR).

## 💡 Key Features

* **🔍 Symptom-based Disease Search:** Users can input symptoms related to oral and dental inflammation. The app analyzes these symptoms to match them with the most probable conditions, providing comprehensive disease details alongside real clinical case images.
* **💊 Antibiotic Information Hub:** A reliable database featuring accurate details on commonly prescribed antibiotics in dentistry. It includes recommended dosages, potential side effects, contraindications, and high-quality images of commercial products available in the market.

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites
* Flutter SDK (version 3.x.x or higher)
* Android Studio / VS Code
* An Android/iOS emulator or a physical device

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/MoazEslam74/AMR-Dental-App.git
2. Navigate to the project directory:
   ```bash
   cd breakpoints-amr-app
3. Install dependencies:
   ```bash
   flutter pub get
4. Run the application:
   ```bash
   flutter run
